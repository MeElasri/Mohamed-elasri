# Cours interactif : structure de base d'un ordinateur

Cours pour les élèves de **tronc commun** (informatique, chapitre 1). Ouvrir `index.html` dans un navigateur : la page fonctionne sans installation.

## Contenu
1. Définitions : information, informatique, ordinateur, système informatique (matériel + logiciel)
2. Schéma fonctionnel (architecture de Von Neumann) cliquable + simulation du trajet d'un calcul
3. Unité centrale : processeur (UC, UAL, registres), carte mère, bus, RAM / ROM / mémoire de masse
4. Périphériques : entrée, sortie, entrée/sortie, stockage
5. Unités de mesure (bit, octet, Ko, Mo, Go, To) + convertisseur
6. Quiz final de 10 questions corrigé

Chaque partie a une activité corrigée automatiquement. La progression est gardée dans le navigateur de l'élève.
