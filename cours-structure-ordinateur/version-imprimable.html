Partie 1

Informatique, information, ordinateur

InformationÉlément de connaissance (texte, nombre, image, son, vidéo) qui peut être codé, stocké, traité et transmis.
InformatiqueScience du traitement automatique et rationnel de l'information à l'aide de machines : les ordinateurs. (INFORmation + autoMATIQUE)
OrdinateurMachine électronique programmable qui reçoit des données, les traite selon des instructions (programmes) et produit des résultats.
Système informatiqueEnsemble formé par le matériel et les logiciels qui travaillent ensemble pour traiter l'information.
Système informatique = Matériel(hardware) : partie physique, on peut la toucher + Logiciel(software) : programmes, on ne peut pas les toucher

Il existe deux familles de logiciels : les logiciels de base (le système d'exploitation : Windows, Linux, Android) qui font fonctionner la machine, et les logiciels d'application (traitement de texte, navigateur, jeux) qui servent à l'utilisateur.

Partie 2

Le schéma fonctionnel d'un ordinateur

Tout ordinateur suit le même principe : entrée → traitement → sortie, avec une mémoire pour garder les données. Ce modèle s'appelle l'architecture de Von Neumann (1945).

Exemple : le trajet du calcul 7 + 5

  1. Entrée : l'élève tape 7 + 5 au clavier, qui transforme chaque touche en binaire (« 7 » → 00110111).
  2. Mémorisation : les codes circulent sur le bus et sont rangés dans la RAM.
  3. Commande : l'unité de commande lit l'instruction « additionner », la décode et donne l'ordre de calculer.
  4. Traitement : l'UAL calcule en binaire 0111 + 0101 = 1100, soit 12.
  5. Résultat : 12 est rangé dans la RAM.
  6. Sortie : le résultat est envoyé à l'écran, qui affiche 12.
  7. Stockage : si l'élève enregistre, le fichier est copié sur le disque dur et sera conservé après l'arrêt.
Partie 3

L'unité centrale : processeur et mémoire centrale

Attention : dans la vie courante, on appelle « unité centrale » la tour (le boîtier). En cours d'informatique, l'unité centrale désigne le processeur + la mémoire centrale.

Le processeur (CPU)

C'est le « cerveau » : il exécute les instructions des programmes. Sa vitesse est sa fréquence, en gigahertz (GHz) : 3,2 GHz = 3,2 milliards de cycles par seconde.

  • Unité de commande (UC) : cherche les instructions en mémoire, les décode et donne les ordres.
  • UAL : calculs (+, −, ×, ÷) et comparaisons (=, <, >, ET, OU).
  • Registres : petites mémoires très rapides dans le processeur.

La carte mère et les bus

La carte mère est le circuit imprimé qui porte le processeur, les barrettes de RAM, la ROM (BIOS), les cartes d'extension et les connecteurs (USB, HDMI, réseau…).

Les bus transportent les informations entre les composants :

  • bus de données : les données ;
  • bus d'adresses : où lire ou écrire ;
  • bus de commande : les ordres.

Partie 4

Les périphériques

Un périphérique est un appareil branché à l'unité centrale. On le classe selon le sens de circulation de l'information.

EntréeDe l'utilisateur vers l'ordinateur : clavier, souris, scanner, microphone, webcam.
SortieDe l'ordinateur vers l'utilisateur : écran, imprimante, haut-parleurs, vidéoprojecteur.
Entrée / sortieDans les deux sens : écran tactile, modem, imprimante multifonction, casque-micro.
StockageMémoires de masse : disque dur, SSD, clé USB, carte SD, DVD.
Partie 5

Mesurer la mémoire : bits et octets

L'ordinateur ne connaît que deux états : le courant passe (1) ou ne passe pas (0). Ce chiffre s'appelle un bit (binary digit). 8 bits forment un octet, qui code un caractère : la lettre A = 01000001. On multiplie par 1024 (210) pour passer à l'unité suivante :

1 octet = 8 bits×1024 →1 Ko×1024 →1 Mo×1024 →1 Go×1024 →1 To
Pour passer à une unité plus petite, on multiplie par 1024 ; pour passer à une unité plus grande, on divise par 1024. Les fabricants de disques utilisent souvent 1000 : un disque « 500 Go » affiche environ 465 Go.

Synthèse

À retenir

Structure
  • Système informatique = matériel + logiciel.
  • Entrée → unité centrale → sortie, avec les mémoires de masse.
  • Unité centrale = processeur + mémoire centrale.
Composants
  • Processeur = UC + UAL ; fréquence en GHz.
  • RAM : lecture/écriture, volatile. ROM : lecture seule, BIOS.
  • La carte mère relie tout par les bus.
Mesures
  • 1 octet = 8 bits.
  • 1 Ko = 1024 o ; 1 Mo = 1024 Ko ; 1 Go = 1024 Mo ; 1 To = 1024 Go.
